# Data

The folder contains the three Excel files supplied with Uribe's replication
package and the processed MATLAB file used by Dynare.

## Raw data

- `raw/gdplev.xlsx`
- `raw/LNU.xlsx`
- `raw/fedfunds.xlsx`

## Processed data

`processed/uribe_data_pp.mat` is generated by:

```matlab
addpath('code/matlab')
build_data
```

The three estimated observables are `obs_dy`, `obs_r`, and `obs_di`. The
change in inflation, `obs_dpi`, is also constructed for smoothing but is not
included as an estimation observable.
